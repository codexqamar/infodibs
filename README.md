# DIBS Informative Website

Static informational website for DIBS, Digital Image Biometric Systems.

## Pages

- Home
- About
- DIBS
- Contact
- Privacy Policy
- Terms & Conditions

## Local Preview

This is a plain HTML, CSS, and JavaScript site. From this folder, run:

```bash
python -m http.server 4177 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:4177/index.html
```

## Structure

- `index.html` - Home page
- `about.html` - DIBS acronym and product purpose
- `dibs.html` - Infrastructure and capabilities
- `contact.html` - Contact form and channels
- `privacy-policy.html` - Privacy policy content
- `terms-and-conditions.html` - Terms and conditions content
- `styles.css` - Main styling
- `tokens.css` - Design tokens
- `script.js` - Navigation and interaction behavior
- `assets/` - Website images and favicon
